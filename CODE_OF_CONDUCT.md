# Code of conduct

This project follows the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).
It applies in the repo's issues, pull requests and discussions, and anywhere someone represents the
project.

To report a problem, email hello@custosa.com. The maintainers at Custosa read every report, keep the
reporter's name private, and act on it as the Covenant describes.
