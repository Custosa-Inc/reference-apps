# Security

The apps hold only synthetic data, but report a problem the way you would for an app holding real
records.

- **Known gaps**, such as the clinic's missing sign-in, are listed in each app's compliance page (for
  the clinic, [HIPAA.md](clinic/HIPAA.md)) and tracked as public issues. Discuss those in the open.
- **Anything else**, please don't open a public issue. Use "Report a vulnerability" on the repo's
  Security tab, and we'll reply there.
